# 第17回　メソッドとカプセル化

## 今日の目的

処理をメソッドに分け、クラスの状態を安全に変更する方法を学びます。前回のCharacterを読み、変更して使います。

## 前回とのつながり

第16回では、クラスのフィールドを直接変更しました。今回は`private`で状態を隠し、メソッドを通して変更します。

## 新しく使うJava

- メソッドの引数と戻り値
- `private`
- getterとsetterの考え方

```java
private int hp;

void damage(int amount) {
    hp = hp - amount;
}

int getHp() {
    return hp;
}
```

## サンプルを読む・予想する

`プログラム/第17回/sample/Main.java`を読む前に、攻撃後のHPと、`getHp()`が返す値を予想します。`hp`を直接変更できない理由も説明します。

## 演習

1. `heal(int amount)`を追加し、HPを回復する。

3. `showStatus`に最大HPを表示する。

変更したら、異なるダメージ量で実行結果を確認します。
