# 第20回　ポリモフィズムで同じ命令を送る

## 今日の目的

親クラス型の変数に異なる子クラスのインスタンスを入れ、同じメソッド呼び出しで異なる処理を実行します。

## 前回とのつながり

第19回では抽象クラスとインタフェースを使いました。今回は`Character`型の配列にHeroとEnemyを入れて、まとめて処理します。

## 新しく使うJava

- 参照型の見方
- ポリモフィズム
- 親クラス型の配列

```java
Character[] characters = { hero, enemy };
for (Character character : characters) {
    character.attack();
}
```

変数の型と、実際に入っているインスタンスを分けて考えます。

## サンプルを読む・予想する

配列の中身がHeroとEnemyなのに、同じ`attack()`を呼べる理由を考えます。表示される攻撃名を順番に予想します。

## 演習

1. `Enemy`クラスを追加して`attack()`を実装する。
2. `Character[]`にHeroとEnemyを追加する。
3. ループ内の処理を変更し、名前も表示する。

## 振り返り

- 実際のクラスごとに処理が変わる仕組み。
