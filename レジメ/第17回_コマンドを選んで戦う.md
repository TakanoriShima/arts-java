## 講義内容

### 1. キーボードから入力する：Scanner

プレイヤーの入力を受け取るために、`Scanner` という道具を使う。この授業では、次の 3 行の形だけ覚えればよい。

```java
import java.util.Scanner;                   // ファイルの一番上に書く

Scanner scanner = new Scanner(System.in);   // 入力の道具を用意する
int command = scanner.nextInt();            // 整数を 1 つ読み取る
```

- `Scanner` は Java に最初から用意されている道具だが、`java.util` という場所にあるので、使う前に `import` の行が必要になる（`import` は第24回でくわしく学ぶ）。
- Pleiades では、コンソールをクリックしてから数字を入力し、`Enter` を押す。

### 2. 配列：同じ種類の値をまとめる

コマンドの名前を、1 つの変数にまとめて入れる。

```java
String[] commands = { "攻撃", "薬草を使う", "にげる" };
```

| 書き方 | 意味 | 値 |
|---|---|---|
| `commands[0]` | 0 番目の要素 | `"攻撃"` |
| `commands[2]` | 2 番目の要素 | `"にげる"` |
| `commands.length` | 要素の数 | `3` |

- 番号（添字）は **0 から始まる**。3 個の配列の最後は `commands[2]`。
- `commands[3]` のように、ない番号を使うと、実行時にエラーになる。

`for` 文と組み合わせると、全部の要素を順に表示できる。

```java
for (int i = 0; i < commands.length; i++) {
    System.out.println((i + 1) + ": " + commands[i]);
}
```

- `i` は 0、1、2 と変わる。画面には 1 から表示したいので `i + 1` にしている。
- `i < commands.length` と書いておくと、コマンドを増やしても `for` 文を直さなくてよい。

### 3. do-while：最低 1 回は実行する

```java
int command;
do {
    System.out.print("コマンドを選ぶ > ");
    command = scanner.nextInt();
} while (command < 1 || command > commands.length);
```

- `do { } while (条件);` は、**先に 1 回実行してから** 条件を調べる。入力は最低 1 回は必要なので、`do-while` が向いている。
- `||` は「または」。1 より小さい、または コマンドの数より大きい番号なら、もう一度聞く。
- 最後の `;` を忘れやすい。

### 4. switch：番号ごとに処理を分ける

```java
switch (command) {
    case 1:
        // 攻撃の処理
        break;
    case 2:
        // 薬草の処理
        break;
    case 3:
        // にげる処理
        break;
}
```

- `command` の値と同じ `case` から実行が始まる。
- `break` がないと、**次の `case` の処理まで続けて実行されてしまう**。
- `switch` の中の `break` は、`switch` を抜けるだけで、`while` ループは抜けない。そこで「にげた」ことを `boolean` 型の変数 `escaped` に記録し、`switch` の後で `while` を抜けている。

### 5. サンプルを読む

`プログラム/第17回/sample/Main.java`

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        // キーボードから入力するための道具
        Scanner scanner = new Scanner(System.in);

        // コマンドの一覧（配列）
        String[] commands = { "攻撃", "薬草を使う", "にげる" };

        // 勇者のステータス
        String heroName = "勇者";
        int heroHp = 30;
        int heroMaxHp = 30;
        int heroAttack = 8;
        int herbCount = 2;

        // 敵のステータス
        String enemyName = "ゴブリン";
        int enemyHp = 40;
        int enemyAttack = 7;

        int turn = 1;
        boolean escaped = false;

        System.out.println(enemyName + "があらわれた！");

        while (heroHp > 0 && enemyHp > 0) {
            System.out.println();
            System.out.println("--- ターン" + turn + " ---");
            System.out.println(heroName + " HP:" + heroHp + "/" + heroMaxHp + "  薬草:" + herbCount + "個");
            System.out.println(enemyName + " HP:" + enemyHp);

            // コマンドの一覧を表示する
            for (int i = 0; i < commands.length; i++) {
                System.out.println((i + 1) + ": " + commands[i]);
            }

            // 1〜コマンドの数 の番号が入力されるまで、くり返し聞く
            int command;
            do {
                System.out.print("コマンドを選ぶ > ");
                command = scanner.nextInt();
            } while (command < 1 || command > commands.length);

            // 選んだコマンドごとの処理
            switch (command) {
                case 1:
                    int damage = heroAttack;
                    if (turn % 3 == 0) {
                        damage = heroAttack * 2;
                        System.out.println("会心の一撃！");
                    }
                    enemyHp -= damage;
                    System.out.println(heroName + "の攻撃！ " + enemyName + "に" + damage + "のダメージ");
                    break;
                case 2:
                    if (herbCount > 0) {
                        heroHp += 15;
                        if (heroHp > heroMaxHp) {
                            heroHp = heroMaxHp;
                        }
                        herbCount--;
                        System.out.println(heroName + "は薬草を使った！ HPが" + heroHp + "になった");
                    } else {
                        System.out.println("薬草がない！");
                    }
                    break;
                case 3:
                    System.out.println(heroName + "はにげだした！");
                    escaped = true;
                    break;
            }

            // にげた、または敵をたおしたら、ループを抜ける
            if (escaped || enemyHp <= 0) {
                break;
            }

            // 敵の攻撃
            heroHp -= enemyAttack;
            System.out.println(enemyName + "の攻撃！ " + heroName + "に" + enemyAttack + "のダメージ");
            turn++;
        }

        // 結果の表示
        System.out.println();
        if (escaped) {
            System.out.println("うまくにげきれた。");
        } else if (enemyHp <= 0) {
            System.out.println(enemyName + "をたおした！");
        } else {
            System.out.println(heroName + "はたおれてしまった…");
        }
    }
}
```

### 8. エラーを体験する

サンプルを実行し、コマンドの入力で `a` のような **数字以外** を入力する。

- コンソールに赤い文字で `Exception in thread "main" java.util.InputMismatchException` と表示され、プログラムが止まる。
- 赤い文字の中の `Main.java:` の後の数字が、エラーが起きた行番号。その行を開いて、何をしている行か確認する（`nextInt()` で整数を読もうとした行）。
- このように、**実行してから起きるエラー**を「実行時エラー（例外）」という。対処の方法は第26回で学ぶ。今は「数字を入力する」と約束して進める。

## 確認問題

**問1**　出力は何か。

```java
int[] hps = { 30, 45, 20 };
System.out.println(hps.length + " " + hps[1]);
```

**問2**　出力は何か（すべて答える）。

```java
int command = 2;
switch (command) {
    case 1:
        System.out.println("攻撃");
    case 2:
        System.out.println("防御");
    case 3:
        System.out.println("逃走");
}
```

**問3**　出力は何か。

```java
int count = 5;
do {
    count++;
} while (count < 3);
System.out.println(count);
```

<details>
<summary>答え</summary>

- 問1：`3 45`（要素は 3 個。添字 1 は 2 番目の要素）
- 問2：`防御` と `逃走`（`break` がないので、`case 2` から後ろが全部実行される）
- 問3：`6`（`do-while` は条件より先に 1 回実行される）

</details>
