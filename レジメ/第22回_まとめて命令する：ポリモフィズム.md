# 第22回　まとめて命令する：ポリモフィズム

## 今回のゴール

- `Hero` や `Wizard` のインスタンスを、親クラス型の `Character` の変数・配列に入れられる。
- 拡張 `for` 文で、パーティー全員に同じ命令（`attack`）を送れる。
- 同じ `attack` の呼び出しでも、中身のクラスによって違う処理が動くこと（ポリモフィズム）を説明できる。

## 前回とのつながり

第21回で、`Character` を受けついだ `Hero` と `Enemy` を作った。今回は魔法使い（`Wizard`）を仲間に加える。勇者と魔法使いは別のクラスだが、どちらも `Character` なので、1 つの配列にまとめて「全員、攻撃！」と命令できる。

## 講義内容

### 1. 親クラス型の変数に、子クラスのインスタンスを入れる

```java
Character c1 = new Hero("勇者", 30, 8, 2);
Character c2 = new Wizard("魔法使い", 20, 5);
```

- `Hero` も `Wizard` も `Character` を受けついでいるので、「`Character` の一種」として `Character` 型の変数に入れられる。
- 変数の型（`Character`）と、実際に入っているインスタンスのクラス（`Hero`、`Wizard`）は別のものとして考える。

### 2. 同じ命令で、違う動き（ポリモフィズム）

`プログラム/第22回/sample/Wizard.java`

```java
// 魔法使い：HP は低いが、魔法で大きなダメージを与える
public class Wizard extends Character {
    public Wizard(String name, int hp, int power) {
        super(name, hp, power);
    }

    // 魔法使いの攻撃：攻撃力の 2 倍の火の魔法
    @Override
    public void attack(Character target, int turn) {
        int damage = getPower() * 2;
        System.out.println(getName() + "は火の魔法をとなえた！ " + target.getName() + "に" + damage + "のダメージ");
        target.damage(damage);
    }
}
```

```java
Character[] party = { hero, wizard };

for (Character member : party) {
    member.attack(enemy, turn);
}
```

- `member` の型はどちらも `Character` だが、`member.attack(...)` で実際に動くのは、**中身のクラスでオーバーライドされた `attack`**。1 人目は `Hero` の攻撃、2 人目は `Wizard` の魔法になる。
- 呼び出す側は、相手が勇者か魔法使いかを気にせず「攻撃しろ」と命令するだけでよい。この性質を **ポリモフィズム（多態性）** という。
- 新しい職業を増やしても、この `for` 文は変えなくてよい。

### 3. 拡張 for 文

```java
for (Character member : party) {
    member.showStatus();
}
```

- 「`party` の要素を 1 つずつ `member` に入れて、くり返す」という意味。添字（`i`）を使わずに全員を処理できる。
- 添字が必要なとき（何番目かを表示する、`%` で順番に選ぶ）は、第17回の `for (int i = 0; ...)` を使う。

配列は、要素の数だけ先に作ってから、後で入れることもできる。

```java
Character[] party = new Character[3];   // 3 人分の入れ物を作る（中身はまだ null）
party[0] = hero;
party[1] = wizard;
```

### 4. できること・できないこと（型で決まる）

```java
Character c = new Hero("勇者", 30, 8, 2);
c.attack(enemy, 1);   // OK：Character に attack があるので呼べる（動くのは Hero の attack）
c.useHerb();          // コンパイルエラー：Character 型には useHerb がない
```

- **呼び出せるメソッドは変数の型で決まり、実際に動く中身はインスタンスのクラスで決まる。**
- そのため、サンプルでは薬草を使うとき、`Hero` 型の変数 `hero` を使っている。
- `Character` 型の変数に入った勇者に `useHerb` させたいときは、次のように「中身が `Hero` か」を調べて、`Hero` 型に変換（キャスト）する方法もある。今は読んで意味が分かればよい。

```java
if (c instanceof Hero) {   // c の中身が Hero なら true
    Hero h = (Hero) c;     // Hero 型として扱う
    h.useHerb();
}
```

### 5. サンプルを読む

`プログラム/第22回/sample/Main.java`（変わったところ）

```java
Hero hero = new Hero("勇者", 30, 8, 2);
Wizard wizard = new Wizard("魔法使い", 20, 5);
Enemy enemy = new Enemy("オーク", 70, 9, 30);

// 味方パーティー：Hero も Wizard も Character 型の配列に入れられる
Character[] party = { hero, wizard };
```

```java
switch (command) {
    case 1:
        // 全員が攻撃する（誰の attack が呼ばれるかは、中身のクラスで決まる）
        for (Character member : party) {
            if (member.isAlive() && enemy.isAlive()) {
                member.attack(enemy, turn);
            }
        }
        break;
```

```java
enemy.attack(findTarget(party, turn), turn);
```

```java
// パーティーに生きているメンバーが 1 人でもいれば true
static boolean isPartyAlive(Character[] party) {
    for (Character member : party) {
        if (member.isAlive()) {
            return true;
        }
    }
    return false;
}

// 敵がねらうメンバーを決める（ターンごとに順番に。たおれているメンバーは飛ばす）
static Character findTarget(Character[] party, int turn) {
    for (int i = 0; i < party.length; i++) {
        Character member = party[(turn + i) % party.length];
        if (member.isAlive()) {
            return member;
        }
    }
    return party[0];
}
```

- `while` の条件は `isPartyAlive(party) && enemy.isAlive()` になった。
- `findTarget` は、ターン数を人数で割った余りで、ねらうメンバーを順番に変えている。メソッドの戻り値が `Character` 型になっている。
