# 第21回　勇者と敵を分ける：継承

## 今回のゴール

- `extends` を使って、`Character` を受けついだ `Hero` と `Enemy` を作れる。
- 子クラスで `attack` を **オーバーライド** し、勇者と敵で違う攻撃にできる。
- `super(...)` と `super.attack(...)` の意味を説明できる。

## 講義内容

### 1. 継承とは

```java
public class Hero extends Character {
    ...
}
```

- `extends Character` と書くと、`Hero` は `Character` のフィールドとメソッドを **すべて受けつぐ**。`Hero` の中に書いていない `showStatus()` や `heal()` も、`hero.showStatus()` のように使える。
- 受けつぐ元を **親クラス（スーパークラス）**、受けつぐ側を **子クラス（サブクラス）** という。
- 子クラスには、その子クラスだけのフィールドやメソッドを追加できる（勇者の `herbCount`、敵の `exp`）。

| クラス | 役割 | 持っているもの |
|---|---|---|
| `Character` | 全員に共通 | 名前、HP、攻撃力、ふつうの攻撃、回復、ダメージ |
| `Hero` | 勇者だけ | 薬草、会心の一撃 |
| `Enemy` | 敵だけ | 経験値 |

### 2. 子クラスのコンストラクタと super(...)

`プログラム/第21回/sample/Hero.java`

```java
// 勇者：Character の機能をすべて受けつぎ、薬草と会心の一撃を持つ
public class Hero extends Character {
    private int herbCount;

    public Hero(String name, int hp, int power, int herbCount) {
        super(name, hp, power);   // 親クラス（Character）のコンストラクタを呼ぶ
        this.herbCount = herbCount;
    }

    public int getHerbCount() {
        return herbCount;
    }

    // 薬草を使う
    public void useHerb() {
        if (herbCount > 0) {
            heal(15);
            herbCount--;
            System.out.println(getName() + "は薬草を使った！ HPが" + getHp() + "/" + getMaxHp() + "になった");
        } else {
            System.out.println("薬草がない！");
        }
    }

    // 勇者の攻撃：3 ターンごとに会心の一撃（1.5 倍）
    @Override
    public void attack(Character target, int turn) {
        if (turn % 3 == 0) {
            int damage = (int) (getPower() * 1.5);
            System.out.println("会心の一撃！");
            System.out.println(getName() + "の攻撃！ " + target.getName() + "に" + damage + "のダメージ");
            target.damage(damage);
        } else {
            super.attack(target, turn);   // 親クラスのふつうの攻撃
        }
    }
}
```

- `super(name, hp, power);` は、親クラスのコンストラクタを呼び出す。名前・HP・攻撃力の準備は `Character` に任せ、`Hero` は薬草の数だけを準備する。**コンストラクタの 1 行目** に書く。
- `name` や `hp` は `Character` で `private` なので、`Hero` の中からも直接は使えない。`getName()`、`getPower()` などの getter を使う。
- `heal(15)` のように、親クラスの `public` メソッドは、子クラスの中でそのまま呼べる。

### 3. オーバーライド

親クラスと **同じ名前・同じ引数** のメソッドを子クラスに書くと、子クラスのインスタンスでは子クラスのメソッドが使われる。これを **オーバーライド** という。

| 呼び出し | 実行されるメソッド |
|---|---|
| `hero.attack(enemy, turn)` | `Hero` の `attack`（会心の一撃あり） |
| `enemy.attack(hero, turn)` | `Enemy` には `attack` がないので、`Character` の `attack` |

- `@Override` は「親クラスのメソッドを上書きするつもりです」という印。名前や引数を間違えたとき、コンパイラがエラーで教えてくれる。
- `super.attack(target, turn)` は、「親クラスの `attack`」を呼ぶ。会心の一撃でないターンは、ふつうの攻撃をそのまま使っている。
- `Character` の `attack` は `turn` を使っていないが、子クラスで上書きできるように、同じ形の引数にそろえている。

`プログラム/第21回/sample/Enemy.java`

```java
// 敵：Character の機能をすべて受けつぎ、たおすともらえる経験値を持つ
public class Enemy extends Character {
    private final int exp;

    public Enemy(String name, int hp, int power, int exp) {
        super(name, hp, power);
        this.exp = exp;
    }

    public int getExp() {
        return exp;
    }
}
```

`プログラム/第21回/sample/Main.java`（変わったところ）

```java
Hero hero = new Hero("勇者", 30, 8, 2);
Enemy enemy = new Enemy("ゴブリン", 40, 7, 12);
```

```java
case 2:
    hero.useHerb();
    break;
```

```java
System.out.println(enemy.getName() + "をたおした！ 経験値" + enemy.getExp() + "を手に入れた");
```

- 薬草の処理が `Hero` に移ったので、`Main` の `case 2` は 1 行になった。
- `Character.java` は、第20回の解答例とほぼ同じ。`attack` から会心の一撃を取り除き、ふつうの攻撃だけにしている。

### 6. エラーを体験する

1. `Hero.java` の `@Override` の下のメソッド名を `atack`（t が 1 つ）に変えて保存する。
2. 「親クラスのメソッドをオーバーライドしていない」というエラーになることを確認する。`@Override` を付けていたおかげで、書き間違いに気付ける。
3. 元に戻す。次に `super(name, hp, power);` の行を消して保存し、エラーを確認する（`Character` には引数なしのコンストラクタがないため）。確認したら元に戻す。

## 確認問題

**問1**　`new B().hello();` の出力は何か。

```java
class A {
    void hello() {
        System.out.println("A");
    }
}

class B extends A {
    @Override
    void hello() {
        super.hello();
        System.out.println("B");
    }
}
```

**問2**　`new Child();` の出力は何か。

```java
class Parent {
    Parent() {
        System.out.println("親");
    }
}

class Child extends Parent {
    Child() {
        System.out.println("子");
    }
}
```

**問3**　次の `Enemy` はコンパイルできるか（`Character` はサンプルと同じ）。

```java
public class Enemy extends Character {
    public Enemy(String name, int hp, int power) {
        super(name, hp, power);
    }

    @Override
    public void atack(Character target, int turn) {
        System.out.println("攻撃");
    }
}
```

<details>
<summary>答え</summary>

- 問1：`A` と `B`（`super.hello()` で親の `hello` を実行してから、`B` を表示する）
- 問2：`親` と `子`（子クラスのコンストラクタは、最初に親クラスのコンストラクタを呼ぶ。`super()` を書かなくても、自動で引数なしの `super()` が呼ばれる）
- 問3：できない（`atack` は親クラスにないメソッドなので、`@Override` がエラーになる）

</details>
