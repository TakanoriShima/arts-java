## 講義内容

### 1. 全体の地図

| クラス | 役割 | 主なメソッド |
|---|---|---|
| `Character` | 全キャラクターの共通部分。HP のルールを守る | `attack`（抽象）、`normalAttack`、`damage`、`heal`、`isAlive`、`showStatus` |
| `Hero` など 4 職業 | 攻撃のしかたの違い | `attack` をオーバーライド |
| `Enemy` | 敵。経験値と強攻撃 | `attack`、`getExp` |
| `Main` | バトルの進行 | `main`、`showAll`、`chooseTarget`、`enemyTurn`、`inputNumber` |

### 2. 1 ターンの流れ

```text
while（味方も敵も残っている）
  ├─ 2 ターン目なら僧侶が加わる
  ├─ showAll：全員の状態を表示
  ├─ inputNumber：コマンドを選ぶ
  ├─ switch
  │    ├─ 1 攻撃  → chooseTarget で敵を選び、全員で攻撃。たおした敵を enemies から外す
  │    ├─ 2 薬草  → hero.useHerb()
  │    ├─ 3 にげる → escaped = true
  │    └─ 4 ためる → hero.powerUp(3)
  ├─ にげた、または敵が全滅 → break
  ├─ enemyTurn：敵がランダムに攻撃。たおれた仲間を party から外す
  ├─ 味方が全滅 → break
  └─ turn++
結果を表示
```

### 3. どこを変えると、何が変わるか

| 変えたいこと | 変える場所 |
|---|---|
| 敵の種類・数・強さ | `Main` の `enemies.add(...)` |
| 仲間の種類・強さ | `Main` の `party.add(...)`、各職業クラスのコンストラクタの引数 |
| ある職業の攻撃のしかた | その職業クラスの `attack` |
| HP の上限・下限のルール | `Character` の `damage`、`heal` |
| コマンドの種類 | `Main` の `commands` 配列と `switch` |
| 敵がねらう相手の決め方 | `Main` の `enemyTurn` |
| 表示のしかた | `Character` の `showStatus`、`Main` の `showAll` |

次回・次々回は、この表を見ながら、自分で機能を追加する。

### 4. String.format：表示を整える

```java
String.format("%dターンで勝利！ 経験値%dを手に入れた", turn, totalExp)
```

| 書き方 | 意味 |
|---|---|
| `%s` | 文字列を入れる場所 |
| `%d` | 整数を入れる場所 |

- `%s`・`%d` の場所に、後ろに書いた値が **順番に** 入る。
- `+` でつなぐより、できあがる文の形が読みやすい。
- 値の型と `%` の種類が合わないと、実行時エラーになる（例：`%d` に文字列を渡す）。

### 5. サンプルを読む

`プログラム/第27回/sample/battle/Main.java`

```java
package battle;

import java.util.ArrayList;
import java.util.InputMismatchException;
import java.util.Random;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        Random random = new Random();
        String[] commands = { "攻撃", "薬草を使う", "にげる", "ためる" };

        Hero hero = new Hero("勇者", 30, 8, 2);
        Priest priest = new Priest("僧侶", 25, 4);

        // 味方パーティー
        ArrayList<Character> party = new ArrayList<>();
        party.add(hero);
        party.add(new Wizard("魔法使い", 15, 5));
        party.add(new Warrior("戦士", 40, 10));

        // 敵のグループ
        ArrayList<Enemy> enemies = new ArrayList<>();
        enemies.add(new Enemy("スライム", 20, 5, 5));
        enemies.add(new Enemy("ゴブリン", 40, 7, 12));
        enemies.add(new Enemy("オーク", 70, 9, 30));

        int turn = 1;
        int totalExp = 0;
        boolean escaped = false;

        System.out.println("魔物の群れがあらわれた！");

        // ===== ターンのくり返し =====
        while (!party.isEmpty() && !enemies.isEmpty()) {
            System.out.println();
            System.out.println("--- ターン" + turn + " ---");

            if (turn == 2) {
                party.add(priest);
                System.out.println(priest.getName() + "が仲間に加わった！");
            }

            showAll(party, enemies);

            // ----- 味方の行動 -----
            int command = inputNumber(scanner, "コマンドを選ぶ", commands);
            switch (command) {
                case 1:
                    Enemy target = chooseTarget(scanner, enemies);
                    for (Character member : party) {
                        if (enemies.isEmpty()) {
                            break;
                        }
                        // ねらった敵をたおしていたら、先頭の敵をねらう
                        if (!target.isAlive()) {
                            target = enemies.get(0);
                        }
                        member.attack(target, turn);
                        if (!target.isAlive()) {
                            System.out.println(target.getName() + "をたおした！");
                            totalExp += target.getExp();
                            enemies.remove(target);
                        }
                    }
                    break;
                case 2:
                    if (hero.isAlive()) {
                        hero.useHerb();
                    } else {
                        System.out.println(hero.getName() + "はたおれていて薬草を使えない！");
                    }
                    break;
                case 3:
                    System.out.println("パーティーはにげだした！");
                    escaped = true;
                    break;
                case 4:
                    hero.powerUp(3);
                    System.out.println(hero.getName() + "は力をためた！ 攻撃力が" + hero.getPower() + "になった");
                    break;
            }
            // にげた、または敵が全滅したら、ここで終わる（turn を増やさない）
            if (escaped || enemies.isEmpty()) {
                break;
            }

            // ----- 敵の行動 -----
            enemyTurn(enemies, party, turn, random);
            if (party.isEmpty()) {
                break;
            }
            turn++;
        }

        // ===== 結果 =====
        System.out.println();
        if (escaped) {
            System.out.println("うまくにげきれた。");
        } else if (enemies.isEmpty()) {
            System.out.println(String.format("%dターンで勝利！ 経験値%dを手に入れた", turn, totalExp));
        } else {
            System.out.println(String.format("%dターン目にパーティーは全滅した…", turn));
        }
    }

    // 味方と敵の全員の状態を表示する（敵には番号を付ける）
    static void showAll(ArrayList<Character> party, ArrayList<Enemy> enemies) {
        for (Character member : party) {
            member.showStatus();
        }
        System.out.println("敵：" + enemies.size() + "体");
        for (int i = 0; i < enemies.size(); i++) {
            Enemy enemy = enemies.get(i);
            System.out.println(String.format("  %d: %s HP:%d/%d", i + 1, enemy.getName(), enemy.getHp(), enemy.getMaxHp()));
        }
    }

    // ねらう敵を番号で選ばせる
    static Enemy chooseTarget(Scanner scanner, ArrayList<Enemy> enemies) {
        String[] names = new String[enemies.size()];
        for (int i = 0; i < enemies.size(); i++) {
            names[i] = enemies.get(i).getName();
        }
        int number = inputNumber(scanner, "ねらう敵を選ぶ", names);
        return enemies.get(number - 1);
    }

    // 残っている敵が、1 体ずつランダムに相手を選んで攻撃する
    static void enemyTurn(ArrayList<Enemy> enemies, ArrayList<Character> party, int turn, Random random) {
        for (Enemy enemy : enemies) {
            if (party.isEmpty()) {
                break;
            }
            Character target = party.get(random.nextInt(party.size()));
            enemy.attack(target, turn);
            if (!target.isAlive()) {
                System.out.println(target.getName() + "はたおれた…");
                party.remove(target);
            }
        }
    }

    // 選択肢を表示し、1〜選択肢の数 の番号が入力されるまで聞いて、その番号を返す
    static int inputNumber(Scanner scanner, String message, String[] choices) {
        for (int i = 0; i < choices.length; i++) {
            System.out.println((i + 1) + ": " + choices[i]);
        }
        int number = 0;
        do {
            System.out.print(message + " > ");
            try {
                number = scanner.nextInt();
            } catch (InputMismatchException e) {
                System.out.println("数字を入力してください");
                scanner.next();
            }
        } while (number < 1 || number > choices.length);
        return number;
    }
}
```

- 第26回の `inputCommand` を、`inputNumber` に名前を変えて、コマンドの選択にも敵の選択にも使えるようにした。メッセージと選択肢を引数で受け取るので、同じメソッドを 2 か所で使い回せる。
- `chooseTarget` は、敵の名前を入れた配列を作ってから `inputNumber` に渡している。画面の番号は 1 から、リストの番号は 0 からなので、`number - 1` 番目を返す。
- `main` の中身は、「何をするか」の流れが中心になり、細かい処理はメソッドに分かれている（第18回の考え方）。
- 敵が全滅したときは、`turn++` の前に `break` している。ここで `break` しないと、勝利したターン数が 1 つ多く表示されてしまう。

### 8. エラーを体験する

1. `chooseTarget` の `return enemies.get(number - 1);` を `return enemies.get(number);` に変えて保存する。
2. 実行して、ねらう敵に **最後の番号**（1 ターン目なら `3`）を選ぶ。`IndexOutOfBoundsException` になることを確認する。
3. 最後以外の番号を選んだときは、エラーにならずに **となりの敵** を攻撃してしまう（論理エラー）。どちらも同じ 1 か所のまちがいから起きている。確認したら元に戻す。

### 演習２-１　ねらう敵を選べるようにする

### 演習２-３　ピンチの表示
