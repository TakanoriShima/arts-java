int hp = 15;

## 第2部　Pleiadesで Java を動かす

### 1. プロジェクトを作る

1. Pleiades を起動し、ワークスペースを選ぶ。
2. メニューの「ファイル」→「新規」→「Java プロジェクト」を選ぶ。
3. プロジェクト名に `java16_sample` と入力する。
4. 「module-info.java ファイルを作成」にチェックが入っていたら外して、「完了」を押す。

### 2. クラスを作る

1. パッケージ・エクスプローラーで `java16_sample` の `src` を右クリックし、「新規」→「クラス」を選ぶ。
2. 名前に `Main` と入力する。「public static void main(String[] args)」にチェックを入れる。
3. パッケージの欄は空のままにする。「デフォルト・パッケージの使用は推奨されません」と表示されるが、今は気にしなくてよい（package は第25回で学ぶ）。
4. 「完了」を押すと、`Main.java` が開く。

### 3. コードを入れて実行する

1. `プログラム/第16回/sample/Main.java` の内容を、開いた `Main.java` に貼り付けて、保存する（`Ctrl` + `S`）。
2. `Main.java` を右クリックし、「実行」→「Java アプリケーション」を選ぶ。
3. 画面下の「コンソール」に実行結果が表示される。

- Java では、**ファイル名とクラス名が同じ**でなければならない（`Main.java` の中は `public class Main`）。
- 保存していない変更は、実行に反映されない。実行する前に必ず保存する。

## 講義内容

### 1. サンプルを読む

`プログラム/第16回/sample/Main.java`

```java
public class Main {
    public static void main(String[] args) {
        // 勇者のステータス
        String heroName = "勇者";
        int heroHp = 30;
        int heroAttack = 8;

        // 敵のステータス
        String enemyName = "スライム";
        int enemyHp = 25;
        int enemyAttack = 6;

        // 今のターン数
        int turn = 1;

        System.out.println(enemyName + "があらわれた！");

        // どちらかの HP が 0 以下になるまで、戦闘を続ける
        while (heroHp > 0 && enemyHp > 0) {
            System.out.println();
            System.out.println("--- ターン" + turn + " ---");

            // 勇者の攻撃（3 ターンごとに会心の一撃で 2 倍）
            int damage = heroAttack;
            if (turn % 3 == 0) {
                damage = heroAttack * 2;
                System.out.println("会心の一撃！");
            }
            enemyHp -= damage;
            System.out.println(heroName + "の攻撃！ " + enemyName + "に" + damage + "のダメージ");

            // 敵を倒したら、敵は攻撃できないのでループを抜ける
            if (enemyHp <= 0) {
                break;
            }

            // 敵の攻撃
            heroHp -= enemyAttack;
            System.out.println(enemyName + "の攻撃！ " + heroName + "に" + enemyAttack + "のダメージ");

            System.out.println(heroName + " HP:" + heroHp + "  " + enemyName + " HP:" + enemyHp);
            turn++;
        }

        // 勝敗の表示
        System.out.println();
        if (enemyHp <= 0) {
            System.out.println(enemyName + "をたおした！");
        } else {
            System.out.println(heroName + "はたおれてしまった…");
        }
    }
}
```

### 2. 実行する前に予想する

実行する前に、次をノートに書く。

- 何ターン目にスライムをたおすか。
- 「会心の一撃！」は何回表示されるか。
- 最後の勇者の HP はいくつか。

### 3. 実行結果

```text

スライムの攻撃！ 勇者に6のダメージ

```

予想と違ったところは、コードのどこでそうなったのかを確認する。

### 4. 使っている文法

| 文法 | コード | 意味 |
|---|---|---|
| 変数と型 | `int heroHp = 30;` | 整数は `int`、文字列は `String` |
| 複合代入 | `enemyHp -= damage;` | `enemyHp = enemyHp - damage;` と同じ |
| 剰余（あまり） | `turn % 3 == 0` | 3 で割った余りが 0 → 3 の倍数のターン |
| 論理演算子 | `heroHp > 0 && enemyHp > 0` | 「両方とも」生きている間 |
| `while` | `while (条件) { ... }` | 条件が `true` の間、くり返す |
| `break` | `break;` | ループをその場で抜ける |
| `++` | `turn++;` | 1 増やす |

- `while` の条件は、ブロックの最初に毎回調べられる。スライムをたおした直後に `break` がないと、たおれたスライムが攻撃してしまう。
- `if` の後の `{ }` の中だけが、条件に当てはまったときに実行される。

### 5. エラーを体験する

わざと間違えて、エラーの見方を確認する。確認したら元に戻す。

1. `int turn = 1;` の最後の `;` を消して保存する。
2. 行の左に赤い印が付く。印にマウスを乗せて、メッセージを読む。
3. `;` を戻して保存し、赤い印が消えることを確認する。
4. 次に、`heroHp -= enemyAttack;` の `heroHp` を `heroHP` に変えて保存する。どんなメッセージが出るか読む。

- Java は大文字と小文字を区別する。`heroHp` と `heroHP` は別の名前になる。
- エラーが出たら、**行番号 → メッセージ → 直前に変えたところ** の順に確認する。

## 確認問題

**問1**　出力は何か。

```java
int turn = 7;
System.out.println(turn % 3);
```

**問2**　出力は何か。

```java
int hp = 10;
int count = 0;
while (hp > 0) {
    hp -= 4;
    count++;
}
System.out.println(count + " " + hp);
```

**問3**　出力は何か。

```java
int total = 0;
int i = 1;
while (i <= 5) {
    if (i == 3) {
        break;
    }
    total += i;
    i++;
}
System.out.println(total);
```

<details>
<summary>答え</summary>

- 問1：`1`（7 ÷ 3 = 2 余り 1）
- 問2：`3 -2`（hp は 10 → 6 → 2 → -2。-2 になった時点で条件が `false` になる）
- 問3：`3`（1 と 2 を足したところで、`i` が 3 になり `break` する）

</details>
