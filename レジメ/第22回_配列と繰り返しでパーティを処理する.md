# 第22回　配列と繰り返しでパーティを処理する

## 今日の目的

配列に複数のCharacterを入れ、拡張forで全員を処理します。前期の配列・繰り返しを、オブジェクトと組み合わせて使います。

## 前回とのつながり

第21回では複数クラスとpackageを扱いました。今回は複数のインスタンスをまとめて管理します。

## 新しく使うJava

- 配列の宣言と初期化
- 配列の要素
- 拡張for
- `length`

```java
Character[] party = { hero, mage };
for (Character character : party) {
    character.showStatus();
}
```

## サンプルを読む・予想する

配列の要素数と、表示される順番を予想します。`party[0]`を別のCharacterに入れ替えた結果も考えます。

## 演習

1. 3人のCharacterを配列に入れる。
2. 拡張forで全員のステータスを表示する。
3. 全員に同じダメージを与える。
4. HPが0のキャラクターを表示する。

## 振り返り

- 配列に何が入っているか説明できるか。
- `length`と添字を正しく使えたか。
- 既存のCharacterクラスを変更せずに処理を追加できたか。

## 発展

最もHPが高いCharacterを探します。
