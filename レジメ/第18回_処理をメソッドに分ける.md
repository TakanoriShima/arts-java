## 講義内容

### 1. メソッドとは

メソッドは、処理に名前を付けてまとめたもの。`main` もメソッドの 1 つ。

```java
// 定義（作る）
static int heal(int hp, int maxHp, int amount) {
    hp += amount;
    if (hp > maxHp) {
        hp = maxHp;
    }
    return hp;
}

// 呼び出し（使う）
heroHp = heal(heroHp, heroMaxHp, 15);
```

| 部分 | 例 | 意味 |
|---|---|---|
| 戻り値の型 | `int` | 返す値の型。何も返さないときは `void` |
| メソッド名 | `heal` | 何をするか分かる名前にする |
| 引数 | `(int hp, int maxHp, int amount)` | 呼び出すときに渡す値を受け取る変数 |
| `return` | `return hp;` | 値を呼び出し元へ返して、メソッドを終わる |

- 今は、`main` から呼び出すメソッドには `static` を付けると覚える（理由は第25回で学ぶ）。
- メソッドは `main` の `}` の後、クラスの `}` の前に書く。

### 2. 戻り値を受け取る

```java
heal(heroHp, heroMaxHp, 15);            // これだけでは heroHp は変わらない
heroHp = heal(heroHp, heroMaxHp, 15);   // 戻り値を代入して、はじめて変わる
```

- 引数の `hp` は、`heroHp` の **値のコピー** を受け取った別の変数。メソッドの中で `hp` を変えても、`heroHp` は変わらない。
- だから、結果を `return` で返し、呼び出し側で代入する。

### 3. 引数の数・型が違う同じ名前のメソッド（オーバーロード）

```java
static void showStatus(String name, int hp, int maxHp) { ... }   // 勇者用
static void showStatus(String name, int hp) { ... }              // 敵用
```

- 引数の数や型が違えば、同じ名前のメソッドを複数作れる。これを **オーバーロード** という。
- 呼び出したときの引数に合うものが選ばれる。自分で作れなくてよいが、読んで「どちらが呼ばれるか」分かるようにする。
- `main(String[] args)` の `args` も引数。起動するときに文字列を渡すための引数だが、この授業では使わない。

### 4. 小数を整数にする（キャスト）

会心の一撃を 1.5 倍に変えた。

```java
return (int) (attack * 1.5);
```

- `attack * 1.5` は小数（`double` 型）になる。`8 * 1.5` は `12.0`。
- `int` 型で返すために、`(int)` を付けて整数に変換する。これを **キャスト** という。小数点以下は切り捨てられる。
- `(int)` を付けないと、「double から int への変換」のコンパイルエラーになる。

### 5. サンプルを読む

`プログラム/第18回/sample/Main.java`（`main` の中は第17回とほぼ同じ。変わったところを中心に読む）

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        String[] commands = { "攻撃", "薬草を使う", "にげる" };

        // 勇者のステータス
        String heroName = "勇者";
        int heroHp = 30;
        int heroMaxHp = 30;
        int heroAttack = 8;
        int herbCount = 2;

        // 敵のステータス
        String enemyName = "ゴブリン";
        int enemyHp = 40;
        int enemyAttack = 7;

        int turn = 1;
        boolean escaped = false;

        System.out.println(enemyName + "があらわれた！");

        while (heroHp > 0 && enemyHp > 0) {
            System.out.println();
            System.out.println("--- ターン" + turn + " ---");
            showStatus(heroName, heroHp, heroMaxHp);
            showStatus(enemyName, enemyHp);

            int command = inputCommand(scanner, commands);

            switch (command) {
                case 1:
                    int damage = calcDamage(heroAttack, turn);
                    enemyHp -= damage;
                    System.out.println(heroName + "の攻撃！ " + enemyName + "に" + damage + "のダメージ");
                    break;
                case 2:
                    if (herbCount > 0) {
                        heroHp = heal(heroHp, heroMaxHp, 15);
                        herbCount--;
                        System.out.println(heroName + "は薬草を使った！ HPが" + heroHp + "になった");
                    } else {
                        System.out.println("薬草がない！");
                    }
                    break;
                case 3:
                    System.out.println(heroName + "はにげだした！");
                    escaped = true;
                    break;
            }

            if (escaped || enemyHp <= 0) {
                break;
            }

            heroHp -= enemyAttack;
            System.out.println(enemyName + "の攻撃！ " + heroName + "に" + enemyAttack + "のダメージ");
            turn++;
        }

        System.out.println();
        if (escaped) {
            System.out.println("うまくにげきれた。");
        } else if (enemyHp <= 0) {
            System.out.println(enemyName + "をたおした！");
        } else {
            System.out.println(heroName + "はたおれてしまった…");
        }
    }

    // 名前と HP を表示する（最大 HP あり）
    static void showStatus(String name, int hp, int maxHp) {
        System.out.println(name + " HP:" + hp + "/" + maxHp);
    }

    // 名前と HP を表示する（最大 HP なし）
    static void showStatus(String name, int hp) {
        System.out.println(name + " HP:" + hp);
    }

    // コマンドの一覧を表示し、正しい番号が入力されるまで聞いて、その番号を返す
    static int inputCommand(Scanner scanner, String[] commands) {
        for (int i = 0; i < commands.length; i++) {
            System.out.println((i + 1) + ": " + commands[i]);
        }
        int command;
        do {
            System.out.print("コマンドを選ぶ > ");
            command = scanner.nextInt();
        } while (command < 1 || command > commands.length);
        return command;
    }

    // 攻撃力とターン数から、ダメージを計算して返す（3 ターンごとに 1.5 倍）
    static int calcDamage(int attack, int turn) {
        if (turn % 3 == 0) {
            System.out.println("会心の一撃！");
            return (int) (attack * 1.5);
        }
        return attack;
    }

    // 回復した後の HP を返す（最大 HP を超えない）
    static int heal(int hp, int maxHp, int amount) {
        hp += amount;
        if (hp > maxHp) {
            hp = maxHp;
        }
        return hp;
    }
}
```

- `main` が「何をしているか」だけの流れになり、細かい「どうやるか」はメソッドの中に移った。
- `inputCommand` は、配列 `commands` と `scanner` を引数で受け取っている。配列も引数にできる。

### 8. エラーを体験する

1. `heroHp = heal(heroHp, heroMaxHp, 15);` の引数を 1 つ消して、`heal(heroHp, heroMaxHp)` にする。
2. 保存すると、引数が合わないというエラーになる。メッセージの中に、メソッドが受け取る引数の型 `(int, int, int)` が書かれていることを確認する。
3. 元に戻す。次に、`heroHp = heal(...)` の `heroHp = ` を消して実行し、薬草を使っても HP が変わらないことを確かめる。**これはエラーにならない**が、結果がおかしい。確認したら元に戻す。

- コンパイルエラーは Pleiades が教えてくれるが、2 つ目のような「動くけれど結果が違う」間違いは、実行結果を見て自分で気付く必要がある。

## 確認問題

**問1**　出力は何か。

```java
public static void main(String[] args) {
    int power = 10;
    int result = addBonus(power);
    System.out.println(power + " " + result);
}

static int addBonus(int attack) {
    attack += 5;
    return attack;
}
```

**問2**　出力は何か。

```java
System.out.println((int) (9 * 1.5));
```

**問3**　出力は何か（2 行）。

```java
public static void main(String[] args) {
    show("勇者");
    show(10);
}

static void show(int hp) {
    System.out.println("A");
}

static void show(String name) {
    System.out.println("B");
}
```
