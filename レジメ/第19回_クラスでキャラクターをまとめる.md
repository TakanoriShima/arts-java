## 講義内容

### 1. クラスとインスタンス

| 用語 | 意味 | バトルでの例 |
|---|---|---|
| クラス | 設計図 | `Character`（キャラクターとは何を持ち、何ができるか） |
| インスタンス | 設計図から作った実物 | 勇者、ゴブリン |
| フィールド | インスタンスが持つ情報 | `name`、`hp`、`maxHp`、`power` |
| メソッド | インスタンスができること | `showStatus()`、`attack(...)`、`heal(...)` |

1 つのクラスから、インスタンスをいくつでも作れる。勇者とゴブリンは同じ `Character` クラスから作られ、それぞれ自分の `hp` を持つ。

### 2. Character クラス

`プログラム/第19回/sample/Character.java`

```java
public class Character {
    // フィールド（キャラクターが持つ情報）
    String name;
    int hp;
    int maxHp;
    int power;

    // コンストラクタ（new したときに最初に実行される）
    Character(String name, int hp, int power) {
        this.name = name;
        this.hp = hp;
        this.maxHp = hp;
        this.power = power;
    }

    // 名前と HP を表示する
    void showStatus() {
        System.out.println(name + " HP:" + hp + "/" + maxHp);
    }

    // target に攻撃する（3 ターンごとに会心の一撃で 1.5 倍）
    void attack(Character target, int turn) {
        int damage = power;
        if (turn % 3 == 0) {
            System.out.println("会心の一撃！");
            damage = (int) (power * 1.5);
        }
        System.out.println(name + "の攻撃！ " + target.name + "に" + damage + "のダメージ");
        target.hp -= damage;
    }

    // HP を回復する（最大 HP を超えない）
    void heal(int amount) {
        hp += amount;
        if (hp > maxHp) {
            hp = maxHp;
        }
    }

    // HP が残っていれば true
    boolean isAlive() {
        return hp > 0;
    }
}
```

- **コンストラクタ**は、クラスと同じ名前で、戻り値の型を書かない。`new` したときに 1 回だけ実行され、フィールドに最初の値を入れる。
- `this.name` は「このインスタンスのフィールド `name`」、右側の `name` は引数。名前が同じなので `this.` で区別する。
- 第18回では `static` を付けていたが、クラスのメソッドには付けない。「インスタンスが自分のフィールドを使って動く」メソッドだから。
- クラスの中のメソッドは、自分のフィールドを引数なしで使える（`showStatus()` の中の `name`、`hp`）。

### 3. インスタンスを作って使う

`プログラム/第19回/sample/Main.java`（変わった部分）

```java
// キャラクターを作る（インスタンスの生成）
Character hero = new Character("勇者", 30, 8);
Character enemy = new Character("ゴブリン", 40, 7);
int herbCount = 2;
```

```java
while (hero.isAlive() && enemy.isAlive()) {
    System.out.println();
    System.out.println("--- ターン" + turn + " ---");
    hero.showStatus();
    enemy.showStatus();

    int command = inputCommand(scanner, commands);

    switch (command) {
        case 1:
            hero.attack(enemy, turn);
            break;
        case 2:
            if (herbCount > 0) {
                hero.heal(15);
                herbCount--;
                System.out.println(hero.name + "は薬草を使った！ HPが" + hero.hp + "になった");
            } else {
                System.out.println("薬草がない！");
            }
            break;
        case 3:
            System.out.println(hero.name + "はにげだした！");
            escaped = true;
            break;
    }

    if (escaped || !enemy.isAlive()) {
        break;
    }

    enemy.attack(hero, turn);
    turn++;
}
```

- `インスタンス名.メソッド名(...)` で、そのインスタンスに命令する。`hero.attack(enemy, turn)` は「勇者が、ゴブリンに攻撃する」。
- `インスタンス名.フィールド名` で、フィールドを読める（`hero.name`、`hero.hp`）。
- `!` は「〜でない」。`!enemy.isAlive()` は「敵が生きていない」。
- 敵の攻撃も `enemy.attack(hero, turn)` の 1 行になった。勇者と同じメソッドを使っている。

### 4. 参照：インスタンスを渡すと、元のインスタンスが変わる

第18回では、`int` の値をメソッドに渡しても、元の変数は変わらなかった。ところが `hero.attack(enemy, turn)` を実行すると、`enemy` の HP は減っている。

- `enemy` という変数には、インスタンスそのものではなく、**インスタンスがある場所（参照）** が入っている。
- メソッドの引数 `target` には、その場所がコピーされる。`target` と `enemy` は **同じインスタンス** を指すので、`target.hp -= damage;` で元のゴブリンの HP が減る。

```java
Character a = new Character("勇者", 30, 8);
Character b = a;       // b は a と同じインスタンスを指す（コピーではない）
b.hp = 10;
System.out.println(a.hp);   // 10
```

## 確認問題

**問1**　出力は何か（`Character` クラスはサンプルと同じ）。

```java
Character a = new Character("勇者", 30, 8);
Character b = a;
b.hp = 10;
System.out.println(a.hp);
```

**問2**　出力は何か。

```java
class Item {
    String name;
    int price;
}
```

```java
Item item = new Item();
System.out.println(item.name + " " + item.price);
```

**問3**　出力は何か。

```java
class Slime {
    String name;

    Slime(String name) {
        name = name;
    }
}
```

```java
Slime s = new Slime("スライム");
System.out.println(s.name);
```

<details>
<summary>答え</summary>

- 問1：`10`（`a` と `b` は同じインスタンスを指している）
- 問2：`null 0`（値を入れていないフィールドは、`String` などは `null`、`int` は `0`。コンストラクタを書かないときは、引数なしのコンストラクタが自動で用意される）
- 問3：`null`（`name = name;` は引数に引数を入れているだけ。フィールドに入れるには `this.name = name;` と書く）

</details>
