# 第25回　文字列と標準APIで表示を整える

## 今日の目的

文字列を連結し、標準APIのメソッドを使ってゲームの表示を整えます。APIの名前を暗記するのではなく、コードを読んで使い方を変更します。

## 前回とのつながり

第24回ではエラーを読んで修正しました。今回は表示結果を確認しながら、メッセージを変更します。

## 新しく使うJava

- `String.length`
- `String.toUpperCase`
- `String.contains`
- `String.format`

```java
String message = String.format("%s のHPは %d", name, hp);
System.out.println(message);
```

## サンプルを読む・予想する

文字列の長さ、含まれる文字、整形後の表示を予想します。実行結果で確認します。

## 演習

1. Characterの表示メッセージを変更する。
2. 名前に特定の文字が含まれるか確認する。
3. `String.format`で戦闘ログを作る。
4. 表示する数字を変更する。

## 振り返り

- Stringのメソッドを呼び出せたか。
- APIの結果を予想できたか。
- 表示の変更を実行確認できたか。

## 発展
