# 第18回　継承とオーバーライド

## 今日の目的

共通する処理を親クラスにまとめ、子クラスで処理を変更する方法を学びます。コードを読んで、どのメソッドが実行されるか予想します。

## 前回とのつながり

第17回では、Characterの状態をメソッドで管理しました。今回はCharacterを基底クラスとして、HeroとEnemyを作ります。

## 新しく使うJava

- `extends`
- `super`
- オーバーライド

```java
class Hero extends Character {
    Hero(String name, int hp) {
        super(name, hp);
    }

    @Override
    void attack() {
        System.out.println("勇者の攻撃");
    }
}
```

## サンプルを読む・予想する

HeroとEnemyの`attack()`を呼び出したとき、表示が同じか違うかを予想します。`super`が何を呼び出しているか確認します。

## 演習

1. `Enemy`に「敵の攻撃」と表示する`attack`を追加する。
2. `Hero`の攻撃メッセージを変更する。
3. 新しい子クラス`Wizard`を作り、別の攻撃メッセージを表示する。

ファイル名とクラス名を一致させてください。

## 振り返り

- 継承で何を共通化できたか。
- オーバーライドで何が変わったか。
- `super`の役割を説明できるか。

## 発展

攻撃力をフィールドに追加し、クラスごとに異なるダメージを表示します。
